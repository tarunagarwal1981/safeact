The whole change

One decorator. A caller-supplied key.

Your side effect stays exactly as you wrote it.

Add @safe and pass a key that names the logical action. The same key seen again returns the stored result instead of re-running — and it holds across process restarts, because the record lives in SQLite, not memory.

  • Exactly-once, even across crashes & retries
  • Honest in-doubt — never a blind retry
  • Sync & async · one file · no server
refund_agent.py
from safeact import safe

@safe(store="agent.db")
def charge_refund(key, customer, amount):
    stripe.charge(customer, amount)   # real side effect
    return {"charged": amount}

# retry-safe: runs once, then replays the result
charge_refund("refund-8842", cust, 50)
charge_refund("refund-8842", cust, 50)  # no double-charge
What the open-source core gives you

Four guarantees.

Enforced in code, underneath any agent framework — and proven in a durable record.

Exactly once

Crash, restart, retry — the action happens once, and holds across process restarts.

Honest in-doubt

Audited

A durable record of every attempt and its outcome — your whole audit trail.

Composable
